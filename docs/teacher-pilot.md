# Sharing SchoolWork with a teacher

SchoolWork is suitable for a small supervised trial using non-sensitive sample work. Treat the release as a pilot, not a school-approved or institution-managed product. Each teacher needs their own eligible TeachGPT account and API key. Never share your key, app profile, saved conversations or memory folder with the installer.

Download the Windows x64 installer from https://github.com/SILLEN69/schoolwork-desktop/releases/latest and verify its checksum. The installer is unsigned, so a managed school computer may require IT approval. Follow the school's installation process.

For a first trial, choose a dedicated sample folder and review Applications & screen in Settings. Disable screen input or narrow application access when it is unnecessary. SchoolWork can run commands with the Windows user's permissions; folder/tool switches are not an operating-system sandbox.

Try three tasks: explain a sample maths problem, describe a non-sensitive image with a model that passed its vision test, and make a small code edit followed by a real check. Review the output and tool activity. Try Stop, restarting the app, and checking for updates. Model reliability and performance depend on TeachGPT and the selected model.

Conversations, images and memory are saved locally, but requested text/images/screenshots can be sent to TeachGPT. Optional Telegram delivers messages/results through Telegram cloud chats. Keep it disconnected for the initial trial unless phone messaging is specifically being evaluated.

Before broad municipal/school deployment, obtain a signed build, independent security review, agreed data/retention rules for TeachGPT and optional Telegram, managed capability settings/deployment, support ownership, accessibility checks and tests on school hardware and networks. These are not established by local tests. SchoolWork currently has no institutional administration console or enforced organizational policy.
