# Downloaded stock sound library

Prepared locally for the SchoolWork launch ad. No effects were synthesised for this mix.

## Kenney Interface Sounds

100 OGG files, downloaded and extracted from the official pack:

https://kenney.nl/assets/interface-sounds

CC0 license supplied in `kenney-interface/License.txt`. Selected files: click_001, confirmation_001, tick_001, open_001 and scroll_001. The complete ZIP is retained locally.

## Mixkit transitions/impact

Downloaded original WAV assets 1485, 1492 and 3005. Used as short swish/whoosh/impact clips in the cue mix. Source URLs, file sizes and SHA-256 hashes are in `sources.json`.

Source collection: https://mixkit.co/free-sound-effects/woosh/

License: https://mixkit.co/license/modal/sfxFree/

The Mixkit license permits use in an end product such as this video, including online marketing. It does not permit redistribution of standalone stock clips with source files or as a sound pack. Keep these downloaded originals local; do not publish this directory in the public repository.

The preview soundtrack edits the owner-uploaded music and these downloaded clips. Processing consists of decoding/resampling, trimming, clip placement, gain adjustment and fades. There are no newly generated whooshes, clicks, tones or impacts.
